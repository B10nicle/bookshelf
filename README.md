# Текущая подборка — 05.11.2026

## Регламент добавления книг

Для всех следующих добавлений действует подробный [регламент для агентов](AGENTS.md): он задаёт проверку ISBN и исключений, выбор темы, загрузку обложки в ImageKit, проверку сборки и публикацию. Новые обложки в опубликованной версии должны использовать CDN-ссылку ImageKit, а не локальный файл.

## Как устроена публикация

Основной код проекта находится в ветке `main`: React-компоненты — в `src/`, данные и исследования — в `research/`, исходные обложки для проверки — в `covers/`.

1. Изменения коммитятся в `main`.
2. Workflow **Deploy GitHub Pages** (`.github/workflows/deploy-pages.yml`) автоматически устанавливает зависимости, запускает `npm test`, собирает React-приложение и разворачивает `dist/` на [GitHub Pages](https://b10nicle.github.io/bookshelf/).

Локально для проверки достаточно выполнить `npm test` и `npm run build`. Папки `dist/` и `ghpages/` — временные артефакты и в Git не попадают.

`npm run build` дополнительно запускает `npm run validate:catalog`: проверяются уникальность ISBN, структура публикационных данных, допустимые темы, HTTPS-источники и ссылки обложек ImageKit.

Актуальный workflow — только **Deploy GitHub Pages**.

**149 изданий в 104 группах.** PostgreSQL (включая PostGIS) и Clojure исключены целиком, их фильтры удалены. Список пользователя от 05.11.2026 применён ко всем соответствующим изданиям. В исследовательском архиве 276 записей, из них 127 исключены; архив не предназначен для прямого импорта в подборку.

При любом пополнении обязательно проверять `research/excluded-works.json`: запреты действуют на будущие издания, новые ISBN и исключённые тематики. Все индивидуальные решения сохранены в `research/decisions.json`; новое исключение имеет приоритет над прежним включением. Список обработанных записей — `research/exclusions-2026-11-05.json`. Исключённые записи оставлены только для учёта запретов и происхождения данных, в `books.xml` и интерфейсе их нет.

Остальные тематические фильтры, группы, поиск и кнопка «Наверх» сохранены. Сведения об изданиях по умолчанию закрыты.

## Личная библиотека

Переключатель «У меня есть» сохраняет владение конкретным ISBN в localStorage (`read-in-60-seconds.catalog.owned.v1`). В группах выбирается отдельное издание; у одиночной книги переключатель доступен и на карточке. «Мои книги» пересекается с поиском, тематикой и издательством. Сведения по умолчанию остаются закрытыми.

Отметки хранятся только в текущем браузере, без синхронизации с аккаунтом или Supabase. Для локальных file:// страниц сохранение зависит от поддержки браузера и адреса файла; при запрете хранения интерфейс сообщает, что выбор действует только в текущей вкладке. Перемещение файла, другой браузер или очистка данных могут сделать сохранённые отметки недоступными.

## ImageKit — перенос обложек

Публичный endpoint: `https://ik.imagekit.io/bookshelf`. Скрипт `tools/upload-imagekit.py` загрузит только выбранные издания из `books.xml` в `/covers` и сохранит адреса в `research/imagekit-manifest.json`. Секретный ключ в файлы и репозиторий не записывается: локально создайте `.env` рядом с этим README по образцу `.env.example`, затем запустите `set -a; source .env; set +a; python3 tools/upload-imagekit.py`. После загрузки сборщик начнёт использовать ImageKit вместо локальной папки `covers`; до этого сайт работает как раньше.
