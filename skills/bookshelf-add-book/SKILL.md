# Bookshelf Add Book

Работай в корне репозитория. Для локальных правил и текущей структуры сначала
полностью прочитай `AGENTS.md`. Не изменяй оставшиеся локальные папки `catalog/`
и файлы `legacy-index.html`, если это не является явным запросом.

## Алгоритм

1. Проверь исключения и дубли: `research/excluded-works.json`,
   `research/records.json`, `research/user-additions-2026-11-17.json`,
   `research/work-groups.json`. Одна запись — конкретный ISBN и конкретное
   издание.
2. Сверь карточку по первичному источнику издателя. Зафиксируй название,
   авторов, издательство, год, ISBN и число страниц. Если они не подтверждаются,
   не публикуй запись без уточнения у пользователя.
3. Выбери существующую тему. Новую кнопку темы добавляй только по прямому
   запросу пользователя. Если это очередное издание уже имеющейся работы —
   добавь ISBN в соответствующую группу.
4. Найди обложку именно этого ISBN. При пользовательской обложке сохрани
   исходник без изменений в `Desktop/images`; подготовь JPG в
   `covers/<ISBN-без-дефисов>.jpg`, затем сними SHA-256 и размеры.
5. Добавь полную запись в `research/user-additions-2026-11-17.json`: URL
   первичного источника, метаданные, путь к обложке, хеш, размеры, проверку
   обложки и `topicCodes`.
6. Для загрузки попроси у пользователя **новый временный приватный ключ
   ImageKit** в этой сессии. Никогда не сохраняй ключ в Git, исходном коде,
   README или ответе пользователю. После загрузки убедись, что в
   `research/imagekit-manifest.json` появилась CDN-ссылка
   `https://ik.imagekit.io/bookshelf/...`.
7. Выполни `npm test` и `npm run build`. Проверь новую запись в
   `src/catalog-data.json`: ISBN, тема и CDN-обложка должны совпадать с
   источником.
8. Закоммить только относящиеся к книге файлы, отправь `main` в `bookshelf`,
   дождись успешного workflow **Deploy GitHub Pages** и сообщи пользователю
   название, тему, ISBN и ссылку на сайт.

Не публикуй запись с локальной обложкой вместо ImageKit URL. Не включай ранее
исключённые книги без прямого отменяющего указания пользователя.
